- **Primary URL:** https://github.com/Asalio123/binance-listing-study (Zenodo DOI 10.5281/zenodo.22976615)
- **Date:** 2026 (65 commits; last-commit date not shown on the page read).
- **Source type:** open-source code + data (GitHub). Reading level: README only.
- **Summary:** An event study of all Binance USDT spot listings 2021-2026 (n=470; 468 with announcement times reconstructed to the minute from Binance's CMS API and cross-checked with Telegram), with prices rebuilt from data.binance.vision and dead tokens retained. Coinbase panel said to "reproduce the fade almost exactly" with no Coinbase numbers on the README.

- **Date:** SSRN posted 2026-04-24; blog 2026-04-10.
- **Source type:** preprint (industry author, Betalabs) + blog. Reading level: SSRN abstract page; blog full text.
- **Summary:** Kim hand-collects 52 unlock events for major Binance-listed assets (Jan 2023-Dec 2025) and tests the 72h window with binomial tests against BTC, ETH and a top-10 index, Bonferroni-corrected over 17 tests. - **Claimed effect / data:** Kim: 46/52 (88.5%) negative 72h returns, mean -16.97% (p about 2e-9), same share underperformed BTC, no regime difference (p=0.24); a post-hoc observation that all 14 unlocks within 60 days of the first listing anniversary were negative (author says that p-value is invalid). Blog: CAR[-30,+30] -15.05% (bootstrap CI -24.8% to -5.5%), n about 36-38; best 1-week rank IC -0.019 (t -2.28), turning positive by 30-42 days; 22 simulated short trades, 77% win rate, +8.9% mean net, -86.6% max drawdown from one squeeze.

- **Data, cost, licence:** Kim CLAIMS replication data and code public (not checked). Unlock calendars: Tokenomist Pro $69/month (all historical events + 2 years forward; commercial licence unclear on Pro), CryptoRank unlocks from $475/month, DefiLlama API $300/month (vendor pages; none documents point-in-time/versioned schedules, so UNLOCK-1's UNVERIFIED stands).
