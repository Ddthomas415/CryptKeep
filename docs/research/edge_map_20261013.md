# Edge map: every strategy family tested so far, 2026-10-13

Operator request: "find them all". This page lists everything tested, its status, and what is still untested.

**Labels:**
- **DISPROVEN** = the tested rules failed after costs.
- **CANDIDATE** = a positive historical result, not established.
- **PENDING** = a registered test whose result is not yet due.
- **UNTESTED** = never run.

Each status applies to the tested rules only, not to every possible variant.

**Multiple testing:** about 600 settings in about 25 families have now been tried. More tries make lucky false positives more likely. Every new test must be registered first and judged with that count in mind.
