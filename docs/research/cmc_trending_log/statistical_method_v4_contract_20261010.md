# V4 bounded statistical feasibility contract

Role: DIRECTOR. Risk: HIGH. Status: READY_FOR_INDEPENDENT_REVIEW.
Operator authorization: repeated "get it all done" after the explicit proposal
for a separately registered study using fresh synthetic samples.
No samples are generated by this contract. V2 and V3 remain closed negative

## Question and limited claim

Can a deliberately conservative reference-calibrated day-mean lower bound control
false positives across the existing finite synthetic family, and what power does
that conservatism cost? This is a feasibility reference, not an empirical CMC
inference method. Passing cannot certify actual market dependence, scale,
missingness, quote-qualified selection or event-weighted inference.

Assumption 1: the six supported generator models and their scale parameters define
the reference family. If the real process lies outside it, reference coverage does
not transfer. Assumption 2: independent hashed seed streams approximate independent
synthetic histories. If they overlap, calibration/confirmation separation fails.

## One fixed candidate, no search

Reuse the unchanged V3 generator and daily equal-weight aggregation by explicit
import, with its source hash locked. Do not edit the historical module or outputs.
Lengths: 90,180,365 days. Supported models: iid, overlap7, persistent, heavy_tail,
volatility_shift, shared_unequal. Refusal models: sparse, random_missing, loss_missing.

For each supported model and length, generate 1,000 independent zero-mean reference
histories under stage `v4_reference_20261010`. Record each daily-series sample mean.
For each length take the maximum over all 6,000 reference sample means as cutoff c.
The candidate lower bound is observed day mean minus c; positive means strictly >0.
This deliberately uses raw means, not an estimated or tuned standard error.
It provides only a one-sided bound; never label it a two-sided interval or the
registered event-weighted result. If any reference history is unavailable, or c
is nonfinite or nonpositive, refuse that length rather than repair it silently.

For a continuous fixed-model null distribution, the maximum of 1,000 independent
samples exceeds its 95th percentile with probability 1-0.95^1000. Across 18
model/length combinations the union-bound failure probability is at most
18*0.95^1000. This is a reference-generation probability, not simultaneous
coverage of actual market reports. The maximum across models is conservative
only for the stated finite family. Location-shift interpretation requires the
unchanged additive-mean supported generator; implementation review must verify it.

Primary methodological reference: NIST, nonparametric tolerance limits based on
order statistics: https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/tolelimi.htm
The cutoff is a tolerance bound on synthetic null sample means, not a tolerance
interval on individual trading returns.

Maximum runtime: 120 seconds per foreground call, checkpoint only between cells;
no background job, polling loop or collector. Maximum one implementation review
and one bounded correction handoff per stage; unresolved findings are documented.
Do not run the full repository suite for this isolated synthetic contract; require
targeted deterministic formula, refusal, identity/grid, no-overwrite and seed tests.

No threshold adjustment after confirmation. Failure reports
`NO_CERTIFIED_REFERENCE_V4`; passing reports `FINITE_FAMILY_REFERENCE_ONLY`.
Neither status enables CMC primary scoring. If conservatism destroys useful power,
report that result rather than weaken the bound. A market-applicable method remains
a separate unresolved research question, not completion by renaming this reference.
